## Project Showcase

**Student Management System** — a .NET 8 Blazor web app with student registration, login, course management, and admin features. University coursework project by Muhammad Afzal Kalwar.

## Features

- Student registration (`Register.razor`)
- Login authentication flow
- Course management pages
- Bootstrap-styled Blazor UI

## Quick Start

```bash
dotnet restore
dotnet run --project studentmanagementsystem
```
